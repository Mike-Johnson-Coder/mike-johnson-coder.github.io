# Multiplayer Chess

A simple multiplayer chess game that can be played on a single computer. This project is built using HTML, CSS, and JavaScript, allowing two players to take turns playing against each other.

## Features

- Play chess on a single computer with two players.
- Basic piece movement and turn-based gameplay.
- Simple and responsive design.

## How to Play

1. Clone the repository or download the `chess.html` file.
2. Open the `chess.html` file in your web browser.
3. Players take turns by clicking on their pieces and then clicking on a valid square to move them.

## Installation

No installation is required. Just open the HTML file in a web browser.

## Technologies Used

- HTML
- CSS
- JavaScript
