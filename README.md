# Windows 11 Installation Simulator

Welcome to the Windows 11 Installation Simulator! This project simulates the installation process of Windows 11 and also includes a simple calculator. The simulator is built using HTML, CSS, and JavaScript and is designed for educational purposes.

## Introduction

This project simulates the step-by-step process of installing Windows 11. It provides a user-friendly interface to guide users through the installation steps. Additionally, the project includes a simple calculator for basic arithmetic operations.

## Prerequisites

Before you begin, ensure you have met the following requirements:

- A modern web browser (e.g., Chrome, Firefox, Edge)
- Internet connection

## Installation

To get started with the Windows 11 Installation Simulator, follow these steps:

1. Clone the repository:
    ```sh
    git clone https://github.com/Mike-Johnson-Coder/mike-johnson-coder.github.io.git
    ```

2. Navigate to the project directory:
    ```sh
    cd mike-johnson-coder.github.io
    ```

3. Open `index.html` in your preferred web browser to start the simulator.

## Usage

### Simulator

To use the Windows 11 Installation Simulator:

1. Open `index.html` in your web browser.
2. Follow the on-screen instructions to simulate the installation process.
3. The simulator will guide you through various steps, including accepting the license agreement, choosing the installation type, and completing the installation.

### Calculator

To use the Simple Calculator:

1. Open `index.html` in your web browser.
2. Use the on-screen buttons to perform basic arithmetic operations such as addition, subtraction, multiplication, and division.

## Simulator

The Windows 11 Installation Simulator includes the following steps:

1. **Welcome Screen**: Introduction to the simulator.
2. **License Agreement**: Accept the Windows 11 license agreement.
3. **Choose Installation Type**: Select between "Upgrade" and "Custom" installation.
4. **Installation Progress**: Simulated installation progress bar.
5. **Completion Screen**: Final screen indicating the installation is complete.

## Calculator

The Simple Calculator includes the following features:

- Basic arithmetic operations: addition, subtraction, multiplication, and division.
- Clear button to reset the calculator display.
- Real-time display updates for user inputs and calculations.
