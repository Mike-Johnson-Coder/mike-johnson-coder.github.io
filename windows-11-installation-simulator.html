Welcome to Windows 11 Installation

Click Next to begin the installation process.

Check System Compatibility

Use the PC Health Check app to verify if your device meets the minimum system requirements for Windows 11.

Backup Data

Ensure you back up all important files and data before proceeding with the installation.

Download Installation Media

Go to the Microsoft Windows 11 download page and download the Media Creation Tool.

Create Bootable USB Drive

Use the Media Creation Tool to create a bootable USB drive.

Boot from USB Drive

Insert the USB drive into your computer and restart it. Access the boot menu and select the USB drive as the boot device.

Start Installation

Select your language preferences and click “Next” to start the installation process.

Choose Installation Type

Select the installation type: Full Upgrade, Keep Data Only, or Clean Install.

Accept License Terms

Read and accept the license terms before proceeding with the installation.

Select Installation Location

Choose the drive where you want to install Windows 11.

Complete Installation

Follow the remaining prompts to complete the installation process. This may take some time.
