Download Installation Media

Go to the Microsoft Windows 11 download page and download the Media Creation Tool.

Create Bootable USB Drive

Use the Media Creation Tool to create a bootable USB drive. Insert your USB drive and select it in the tool to download Windows 11 and create a bootable installation media.

Boot from USB Drive

Insert the USB drive into your computer and restart it. Access the boot menu (usually by pressing F12, F2, or Del) and select the USB drive as the boot device.

Start Installation

Once the Windows Setup screen appears, select your language preferences and click “Next”. Follow the on-screen instructions to start the installation process.
